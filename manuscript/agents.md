# agents.md

Use `manuscript-agent` for all manuscript work.

Canonical instructions are in `AGENTS.md` and the agent definition is in `manuscript-agent.md`.

Never write an absolute path into any manuscript file or build artifact. The repository is public and the manuscript is submitted for blind review, so absolute paths would deanonymize the author. Record paths repo-relative.

CLI commands are documented in both files under the manuscript workflow command sections.
